# Community sayings

Original sayings and practical tips written for VerbeApp by its contributors. They are not quotes
from literature, and the app always labels them as community content.

Each contributor has one file, e.g. `data/community/marcin.json`:

```json
{
  "$schema": "../schema/community-collection.schema.json",
  "contributor": "Marcin",
  "items": [
    {
      "id": "two-minute-start",
      "text": "If a task feels too big, do only the first two minutes of it. Starting is the hard part.",
      "tags": ["productivity"],
      "license": "CC0-1.0",
      "inspiredBy": { "url": "https://www.reddit.com/r/LifeProTips/", "title": "r/LifeProTips" }
    }
  ]
}
```

Rules:

- Write in your own words. Ideas are free to reuse; other people's wording is not, so do not copy
  posts, comments or quotes from websites. `inspiredBy` may link to where you found the idea.
- Every item is released under CC0 1.0 (public domain).
- Keep it under 400 characters and useful on its own.
